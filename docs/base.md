# 基础知识

信息量形式为 $I(p) = -K\log p$。 其中 log的底数可以自己取，p是概率

---

香农熵为$H(X)=\sum_{i=1}^np_iI(p_i)=\sum_{i=1}^np_i\log_2p_i$ 它表示：在最优编码下，平均每个符号至少需要多少比特来描述，也表示系统的不确定性大小。

---

交叉熵$H(p,q)=-\sum_x p(x)\log_2q(x)$。推理过程：现在真实数据仍然服从 $p(x)$，但我们不知道真实分布，或者我们用模型估计了一个分布q(x)，如果我们按照q设计编码，那么理想码长为$-\log_2q(x)$ 但是$x$出现的概率仍然是 $p(x)$，所以平均码长为$H(p,q)=-\sum_x p(x)\log_2q(x)$。直观上，交叉熵：真实分布是 p，却用分布 q 编码时的平均码长。

---

交叉熵与KL散度的关系

$
H(p,q) = -\sum_xp(x)[\log p(x)+\log \frac{q(x)}{p(x)}]= -\sum_xp(x)\log p(x)-\sum_xp(x)\log \frac{q(x)}{p(x)}
$

而KL散度为$\sum_xp(x)\log \frac{p(x)}{q(x)}$

第一项是熵$H(p)$，第二项是负的KL散度，由于kl散度大于等于0，只有p=q的时候等于0，因此用错误的分布 q 编码真实分布 p，平均码长不会比用真实分布 p 自己编码更短；只有 q=p 时才达到最优。所以机器学习中最小化交叉熵，本质上是在让模型分布 q 逼近真实分布 p

交叉熵与最大似然之间的关系：

设数据集为
$
D = \{{(x_1,y_1)},...(x_N,y_N)\}
$
模型输出条件概率为
$
q_\theta(y|x)
$，

参数为$\theta$。假设样本独立，则似然函数为

$L(\theta) = \prod_{n=1}^{N} q_\theta(y_n|x_n)$

加个log

$\log L(\theta) = \sum_{n=1}^{N} \log q_\theta(y_n|x_n)$

最大似然，等价于最小化负对数似然

$-\log L(\theta) = -\sum_{n=1}^{N} \log q_\theta(y_n|x_n)$

对于one hot， 交叉熵

$L = -\log q_y$

两者平均是等价的

# torch

torch中，维度编号从 0 开始，dim=0 是“最外层/最慢变化”的维度，dim=-1 是“最内层/最快变化”的维度。dim=d 表示“沿第 d 维进行归约/操作”，操作后该维长度通常变为 1（若 keepdim=True）或被删除（默认）。... 是 Python 的 Ellipsis 对象，在张量索引里表示：这里有多少维我不管，先原样保留，只关心我明确写出的那些维。
